# Tela de Login Glassmorphism

Interface moderna e responsiva para tela de login desenvolvida com HTML5 e CSS3, utilizando efeito de vidro fosco (*Glassmorphism*), ícones dinâmicos e tipografia personalizada.

---

### ✨ Funcionalidades
- **Efeito Glassmorphism:** Cartão de login semi-transparente com efeito de desfoque no fundo (`backdrop-filter: blur`).
- **Campos Interativos:** Entradas para e-mail e senha com ícones integrados via **Boxicons**.
- **Opções de Usuário:** Opção de "Lembrar-me" e link para recuperação de senha.
- **Botão Customizado:** Animação suave no botão de envio com efeito de *hover*.
- **Opção de Cadastro:** Link direto para a página de registro de conta.

---

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do formulário.
- **CSS3:** Estilização com variáveis, Flexbox, efeito Glassmorphism e transições.
- **Google Fonts:** Fonte [Lexend](https://fonts.google.com/specimen/Lexend) importada diretamente.
- **Boxicons:** Biblioteca de ícones interativos.
